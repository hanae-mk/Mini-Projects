Those are 2 Console projects made with C++ :

The first project is a game called Stone,Paper,Scissor which the user and the computer play the game then the system decides who wins all depending on the score for both user & computer

The second project is a math game which the user choose the level of difficulty (Easy, Medium, Hard or Mix) and the operation type (Addition, Substraction, Multiplication, Division or Mix)
and solving each operation then the system will show to the user if the answer is true or false based on the answer & in case if the answer is false the system will show the right answer and in the end of the game the user will see the number of correct & wrong answers
